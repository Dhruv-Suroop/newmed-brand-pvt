# NewMed Skills — Design Brief for Claude Design

Hand this whole file to Claude Design. It's everything needed to design **on-brand** NewMed Skills material (posters, social, decks, ads, UI). If a request conflicts with this, ask before breaking it.

---

## Who NewMed Skills is
A global healthcare workforce company. It **sources** clinicians from India, Asia and Africa and **deploys** licensed, ready staff to the UK, GCC, Europe and North America. It unifies a fragmented journey into **one platform, from first assessment to first shift**. Positioning is **clinical calm** — trustworthy, reassuring, never hype.

---

## 1. Palette — exactly these 7 colours. Never invent one.

| Name | Hex | Use |
|---|---|---|
| **NewMed Orange** | `#FF5122` | the hero — a *signal*, used sparingly |
| **Yellow** | `#FF9D00` | warmth beside orange |
| **Maroon** | `#7C3134` | depth, serious moments |
| **Deep Brown** | `#391E1A` | all text + dark surfaces (warm near-black) |
| **Teal** | `#93CCCD` | the one cool note; most sparing |
| **Off White** | `#F4F1EA` | the page / main light surface |
| **Off White (deep)** | `#EFE9E0` | sunken surfaces, cards |

**Proportions — this is the whole feel.** Keep it mostly light and soft; use dark/saturated colours *minimally*.
- Default mix: **~70% Off White · 20% NewMed Orange · 10% Maroon**.
- Bolder variant: **~70% Maroon · 10% Orange · 10% Yellow · 10% Off White**.
- No white, no tints, no shades. Words to never use: coral, chevron, amber, cream, linen, clay.

---

## 2. The arrow — the core motif

**One shape:** rounded start cap · stretchable body · pointed cap. It's always called an **arrow**.

**Locked geometry (never changes):** corner radius = **10% of the height**; point length = **42.6% of the height**. Only the colour changes — the radius and the point angle never do. (If you build it: master height 165.88; radius = 16.59·s; point = 70.59·s, where s = height ÷ 165.88.)

**Nesting:** a following arrow uses a **notched** (concave) left that mirrors the point, so arrows **interlock seamlessly with zero gap** — use for journeys, sequences, and proportion bars.

**Fill:** default is the **Yellow → Orange gradient** (organic and soft, never hard-edged). Flat orange, yellow, or deep brown are the alternates.

**Text inside an arrow:** Off White on orange / gradient / deep-brown fills; Deep Brown on yellow. Always legible.

**Ways to use it:**
1. **Headline highlight** — the key phrase sits *inside* the arrow. Min 2 words; highlight the phrase carrying the movement or promise (never filler, never the negative half of a sentence); make it the **last line** so nothing orphans; **one arrow per headline**.
2. **CTA button** — arrow-shaped, for emphasis.
3. **Eyebrow badge** — outline arrow; can hold an icon.
4. **Number / icon chip** — glyph fills ~60% of the chip, big and confident.
5. **Portrait container** — clips the **bottom half only**; head & shoulders break freely out the top.
6. **List rows**, **nested journeys**, and **poster-scale** arrows holding photography or whole sections.

**Never:** describe the shape in words next to it; box a cutout fully inside an arrow; hard-edged gradients; anything that bounces or springs.

---

## 3. Typography
- **Mona Sans only** (humanist grotesk, calm and legible — reads clearly for English-as-a-second-language audiences).
- Display / headings: **tight and semibold (600), never heavier**. Body: **regular (400)**, 1.5 line-height, spaced for lightness.
- Type and the arrow interlock — the headline flows *into* the highlight.

---

## 4. Iconography
- **Single colour**, **thick strokes**, **no sharp corners**, **simplified and clean — no clutter**. Rounded, calm, legible. (Material Symbols rounded is a fair reference.)

---

## 5. Voice (so visuals match the words)
Three tones, pick by context:
- **Clinical** — factual, complete, to the point, no emotion. (Compliance, licensing, terms.)
- **Standard** — the default. Clear *and* empathetic; simple, accessible. (Website, emails, social.)
- **Bedside** — one-to-one, warm and reassuring; speaks to real anxieties (fees, visas, arriving alone). (Hero headings, candidate conversations.)
Warmth comes from naming real stakes, not soft words. Confidence from substance, never volume.

---

## 6. Design ethos
Be bold, never lazy — think Pentagram / Studio Dumbar / Collins. **One dominant move per composition.** Build the layout *from* the arrow / gradient / cutout system; if a composition would work without the brand elements, it isn't done. Generous whitespace — the calm is in the restraint. No orphan words. Nothing bounces.
