# Corpus

The full NewMed Skills manual as self-contained HTML — CSS, JavaScript and the
Mona Sans font are inlined, so these open offline with no server and no network.

This is **ground truth**. Where anything in `reference/` disagrees with these
files, these win: they are generated from the live manual by `build_pages.py`.

Eight files, one per section: brand, logo, arrow, icons, colour, type,
applications, home.

They also carry the live generators — arrow, pattern, icon, data-viz and
gradient — so you can see the rules executing rather than described.
