**StepFlow** — the journey as arrow-shaped cards (01 Source → 06 Retain), each notched so the previous point nests in. The brand's signature process pattern.

```jsx
<StepFlow />
<StepFlow steps={["Apply","Screen","License","Deploy"]} active={2} tone="cream" />
```

`active` fills the current stage orange. Use on cream or gradient backgrounds (`tone="white"`), or `tone="cream"` on white.
