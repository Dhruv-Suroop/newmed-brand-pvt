Why this works better than a PDF

The arrow's geometry is a ratio that is easy to describe and easy to get wrong: corner radius 10% of height, point 42.6% of height. Written in prose, it gets approximated. So this ships arrow.js — the same file that draws every arrow in this manual.

An AI told to call the function cannot get the shape wrong. One told to read about the shape can, and does. The same goes for the gradient wash, the optical centring of icons, and the size floor below which an arrow stops reading as an arrow.

How to use it

Works with Claude, and with any assistant that can read a folder of files.

  1. Download and unzip. You get a folder called NewMed Skills Design System.
  2. Add it to Claude Design as a skill. Upload the whole folder — it already contains a SKILL.md with the right frontmatter, so it is recognised automatically. In any other assistant, upload the folder and say “follow the brand rules in SKILL.md”.
  3. Ask for what you need — a deck, a social post, a poster, a landing page. It will use the right colours, draw correct arrows, and write in the brand voice.
  4. Check it against this manual. The skill contains the full manual offline, so it can cite its own source — ask it why it made a choice.

The rules it enforces

The ones most often broken, and the reason each exists.

Seven colours, no more

No tints, no shades, no white. The four data-visualisation colours are charts only and never touch a brand surface.

70 / 20 / 10

Roughly 70% neutral, 20% orange, 10% maroon. The calm comes from how little of the palette you spend.

One highlight per headline

Two words minimum, on the phrase carrying the promise — never the negative half — and always the last line, so nothing orphans.

The 0.85× floor

Below 0.85× the arrow's height the point and radii stop resolving and it reads as a lozenge.

Cutouts break out

A portrait is clipped by the arrow's bottom half only. Head and shoulders break out of the top. Never boxed inside.

Bigger, one weight down

Display at 600, never heavier, at poster scale. Weight 600 at 150px has presence; 800 at 60px is just heavy.

One dominant move

A full-bleed band, or a poster-scale arrow, or a giant photograph. One. Two competing moves read as noise.

Nothing bounces

Calm opacity and settle on a decelerating curve. Reduced motion must fail open, never leave a page blank.

Keeping it current

The skill is generated from this manual. When the manual changes, regenerate and re-download — the corpus and the engine come straight from the live files, so they cannot quietly drift. If the skill and this site ever disagree, this site wins.
