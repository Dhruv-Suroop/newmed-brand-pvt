# AI Handoff — NewMed Skills static site

You are picking up a **static export of a Framer site** (NewMed Skills) to take it
to production. This document is written for you, the next AI/engineer. Work through
it top-to-bottom; items are ordered by priority (P0 = blocks launch).

Before touching anything, read `README.md` in this folder for how the export is
structured and the **hard rule that it must be served over HTTP, never `file://`**
(it uses ES modules). Verify locally with `python3 -m http.server 8000`.

> Throughout this doc, `<DOMAIN>` means the final production origin with no trailing
> slash, e.g. `https://www.newmedskills.com`. Substitute it everywhere.

---

## How this site is built (read once, saves confusion later)

- It's a **compiled snapshot**, not editable source. `index.html` + minified React/
  Motion bundles in `js/`. Structural/content changes should ideally be made in the
  original **Framer project and re-exported**, not hand-edited here. Small, targeted
  fixes (meta tags, URLs, a form endpoint) in `index.html` are fine.
- `js/rerouter.js` is **auto-generated by the export** and loads first in `<head>`.
  It rewrites `framerusercontent.com` CDN URLs to the local `images/` copies so the
  site runs fully offline. Leave its internals alone. (It also no-ops
  `navigator.sendBeacon`, which disables Framer's built-in analytics — see P3.)
- Only external runtime dependency is **Google Fonts** (`fonts.gstatic.com`); fonts
  are also mirrored locally in `images/*.woff2`.

## P0 — Blocks launch

### 1. The contact form does not submit
The page has a Framer form (`<form class="framer-dgvsyw">`, 14 inputs + 1 textarea).
Framer forms POST to `framer.com/api` (confirmed in `js/framer.*.mjs`). **That
endpoint only works on Framer's own hosting — on a static host, submissions fail
silently.** You must wire the form to a real backend. Options:
  - A form service (Formspree, Basin, Web3Forms) — set the form `action`/handler.
  - The client's own API endpoint.
  - Re-enable it via re-hosting on Framer (defeats the purpose of the export).

While you're in there, the form also needs cleanup (see P2 #7 & #8): placeholder
text still says `jane@framer.com` / `Jane Smith`, and several fields share generic
`name` attributes (multiple `name="Email"`, plus `comments`/`feedback`/`notes`/
`remarks`/`title`/`subject`). Give fields sane, unique names before hooking up a
backend or the submitted payload will be ambiguous.

### 2. Serve `.mjs` with a JavaScript MIME type
The site is ES modules. The host **must** serve `js/*.mjs` as
`text/javascript` (or `application/javascript`). Some static hosts/CDNs don't do
this by default for `.mjs`, which makes the whole page break with a MIME/module
error. Verify in the browser Network tab after deploy. (Nginx: add
`types { text/javascript mjs; }`. S3: set `Content-Type` metadata on `.mjs` objects.)

## P1 — SEO / production domain (do all of these once `<DOMAIN>` is known)

The export hard-codes the Framer **staging** domain and uses relative social-image
paths. Everything below depends on the real domain.

### 3. Replace the staging domain
`https://newmed.framer.website/` appears in `index.html` in two JSON-LD schema
blocks (`Organization` and `EmploymentAgency`, the `"url"` field). Replace both with
`<DOMAIN>/`. (It also appears once inside `js/rerouter.js` as an asset mapping —
harmless, leave it.)

### 4. Make social-share images absolute
`og:image` and `twitter:image` currently point to the **relative** path
`images/5h8j8woffu326m1idhsbgonwhy.png`. Social platforms (LinkedIn, X, WhatsApp,
Facebook) cannot fetch relative URLs — the preview image will be blank. Change both
to `<DOMAIN>/images/5h8j8woffu326m1idhsbgonwhy.png`. (The image itself is correct:
a 1201×631 NewMed logo-on-gradient card, already in `images/`.)

### 5. Add a canonical + og:url tag
Neither exists. Add inside `<head>`:
```html
<link rel="canonical" href="<DOMAIN>/">
<meta property="og:url" content="<DOMAIN>/">
```

### 6. Create `robots.txt` and `sitemap.xml`
Not included in the export (Framer's host generates them; a static export does not).
Add both at the site root.

`robots.txt`:
```
User-agent: *
Allow: /

Sitemap: <DOMAIN>/sitemap.xml
```

`sitemap.xml` (single-page site — expand if pages are added):
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc><DOMAIN>/</loc>
    <changefreq>monthly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>
```

## P3 — Optional / recommended

### 11. Analytics
There is **no analytics** on this build. Framer's built-in analytics is disabled
(rerouter no-ops `sendBeacon`). If the client wants tracking, add GA4 / Plausible /
Fathom via a `<script>` near the end of `<head>`.

### 12. (Optional) Fully self-host fonts
The only external request is Google Fonts. If total offline/privacy is required,
serve the already-mirrored local `images/*.woff2` and drop the `fonts.gstatic.com`
`<link>`s. Not required — the local fonts already exist as a fallback.

### 13. Hosting hygiene
Enable gzip/brotli, long-cache the hashed `js/*.mjs` and `images/*` assets, set a
404, and serve over HTTPS.
