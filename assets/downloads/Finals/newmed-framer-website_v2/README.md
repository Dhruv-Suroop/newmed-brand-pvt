# NewMed Skills — Static Site Export (v2)

Static export of the NewMed Skills website, originally built in Framer
(staging URL: https://newmed.framer.website).

> 👉 **Taking this site to production?** Read **[`AI-HANDOFF.md`](AI-HANDOFF.md)** —
> a prioritized checklist of everything left to do (contact form, production domain,
> `robots.txt`/`sitemap.xml`, schema URLs, social images, analytics). Written to be
> handed to the next AI or engineer.

## ⚠️ Must be served over HTTP

Do **not** open `index.html` directly from the filesystem (`file://`) — the site
uses ES modules, which browsers block over `file://`, so styling, animations and
interactive components break silently.

Run any static file server from this folder instead:

```sh
npx serve .
# or
python3 -m http.server 8000
```

Then open http://localhost:8000. In production, host it on any static host
(Nginx, S3/CloudFront, Vercel, Netlify, or embedded in your platform) — no build
step, no Node server, no external dependencies required.

## Contents

- `index.html` — the entire site (single page; nav uses `#about`, `#platform`, `#contact` anchors)
- `js/` — the Framer runtime (React + Motion) and compiled page/component code
- `js/rerouter.js` — **auto-generated by the export**; rewrites the original
  `framerusercontent.com` CDN URLs to the local `images/` copies so the site
  works fully offline / self-hosted. Loaded first in `<head>`; do not remove.
- `images/` — all images, SVGs and self-hosted fonts

## SEO & structured data

Exported correctly from Framer and present in `<head>`:

- `<title>`, meta description, Open Graph (`og:*`) and Twitter card tags.
- **3 JSON-LD schema blocks** (added via Framer's "End of `<head>`" custom code):
  `FAQPage`, `Organization`, and `EmploymentAgency`.

## ⚠️ Before going live on your own domain

A static export hard-codes the Framer **staging** domain and uses relative
social-image paths. Review these once the production domain is decided:

- **`og:image` / `twitter:image` are relative** (`images/…`). Social platforms
  (LinkedIn, X, Facebook, WhatsApp) require **absolute** URLs — change to
  `https://<your-domain>/images/…` or the share preview image will not load.
- **Schema `url` = `https://newmed.framer.website/`** in the `Organization` and
  `EmploymentAgency` blocks — update to the production URL.
- **No `robots.txt`, `sitemap.xml`, or `<link rel="canonical">` are included.**
  Framer's hosting serves these automatically, but they are **not** part of a
  static export. Add them once the final domain is known.

## Notes for integration

- The site is fully self-contained; the only external requests are Google Fonts
  (`fonts.gstatic.com`). Fonts are also mirrored locally in `images/*.woff2`.
- This is a **compiled snapshot**, not editable source. The JS is minified React —
  small text/style tweaks can be made in `index.html`, but structural changes
  should go through the original Framer project and be re-exported.
- The page ships React inside its own bundle. If you embed it inside a React app,
  isolate it (serve it on its own route or in an iframe) rather than mounting your
  own components into its DOM.
