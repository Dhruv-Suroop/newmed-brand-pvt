**ArrowBadge** — the eyebrow/category tag: coral text in an outline arrow, optionally led by a solid arrow chip holding a glyph.

```jsx
<ArrowBadge icon={<GlobeGlyph/>}>Healthcare Workforce Readiness</ArrowBadge>
```

Use above hero headlines and as section kickers on marketing surfaces (the plain `Eyebrow` remains for dense product UI and slides).
