**ArrowList** — next-steps / key-points list: numbered solid arrow chips beside full-width cream arrow rows.

```jsx
<ArrowList items={[
  "Schedule a workforce planning discussion",
  "Launch a pilot recruitment programme",
  "Request a workforce readiness assessment",
]} />
```

Pass `{text, icon}` objects to swap numbers for glyphs. `tone`/`textColor` recolor rows (never reshape).
